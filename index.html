Aturan deteksi versi 1:
• Bullish OB = candle bearish terakhir sebelum candle bullish impulsif menutup di atas swing high terkonfirmasi (BOS).
• Bearish OB = candle bullish terakhir sebelum candle bearish impulsif menutup di bawah swing low terkonfirmasi (BOS).
• Zona OB memakai rentang high–low candle sumber. Zona dianggap invalid jika candle berikutnya menutup melewati sisi distal zona (bullish: di bawah low; bearish: di atas high).
• Status “Mendekati” memakai jarak default 0,30% dari tepi zona. Ubah nilainya sesuai kebutuhan.

Penting: Ini definisi OB mekanis buatan scanner, bukan pembacaan kotak LuxAlgo. OB adalah area kandidat, bukan sinyal entry. Uji hasil di chart sebelum transaksi. Data memakai API publik Binance dan dapat terkena batas permintaan/koneksi.
